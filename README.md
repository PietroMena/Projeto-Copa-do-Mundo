## Projeto
-Portal de noticias para a copa do mundo
-Sistema de chaveamento dos grupos
-Login para ADMs

## Descrição
-Por enquanto a ideia é fazer um site que contenha um portal de notícias para a copa do mundo de 2026 
e também uma página para os chaveamentos das chaves de grupos.
A conta de amdin serve para quem for colocar ou editar alguma notícia na página, 
o banco de dados irá salavar essas informações e as de login
